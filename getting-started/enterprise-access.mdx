---
title: "企业开通"
description: "由商务或管理员完成账号开通，确认权限后开始对接。"
---

Vizluma API 仅面向已开通的企业客户，**没有自助注册流程**。文档中的所有调用示例均从“你已经获得 API Key”开始。

<Steps>
  <Step title="联系对接人员">
    向与你对接的商务或管理员说明所需模型、业务场景、预计调用量、峰值并发和账务需求。请使用已有的企业对接渠道。
  </Step>
  <Step title="确认账号与调用权限">
    管理员开通账号，并与你确认模型范围、可用额度、单价和调用限制。开通账号不代表默认获得所有模型权限。
  </Step>
  <Step title="获取 API Key">
    按管理员提供的方式获取或创建用于接口调用的 API Key。控制台登录密码不是 API Key；不要把登录凭证填到请求头中。
  </Step>
  <Step title="完成联调">
    从 [快速开始](/quickstart) 的单张图片示例验证网络、鉴权、模型权限和图片下载，再逐步接入业务。
  </Step>
</Steps>

## 上线前确认

- 开发、测试与生产使用独立的 API Key。
- API Key 仅存放在服务端环境变量或密钥管理系统中。
- 业务服务、负载均衡和客户端允许长耗时请求。
- 并发规模、账户额度和报价已经确认。
- 成功结果会及时保存到企业自己的存储中。
- 发生超时后不会直接自动重发，避免重复生成和重复费用。

如果暂未开通，请联系你的商务或管理员。**不需要、也无法通过自助注册完成开通。**
