已有账号可直接 [登录](https://vizluma.online/sign-in)；新用户可通过 [注册页](https://vizluma.online/sign-up) 按页面提示完成注册。企业统一开通、VIP 分组及专属报价通过已有商务或管理员办理。

<Steps>
  <Step title="准备账号">进入官网完成注册或登录。验证码、多因素验证等要求以页面和账号配置为准。</Step>
  <Step title="确认可用额度">登录 [控制台](https://vizluma.online/console)，查看余额和已开通范围。注册成功不代表默认获得免费额度、VIP 或全部模型权限。</Step>
  <Step title="获取 API Key">在账户的 API Key／令牌管理入口创建或取得 Key。按需要设置名称、有效期、额度和模型范围；具体可选项以当前页面为准。</Step>
  <Step title="服务端配置">把完整 Key 注入服务端环境变量。列表中的掩码 Key 不能调用接口；不要用账号密码或登录会话代替 Key。</Step>
  <Step title="完成首次请求">先 [查询模型](/api-reference/models)，再按 [快速开始](/quickstart) 发送最小请求，并核对结果和费用。</Step>
</Steps>

## 企业账号与 VIP

请提供需要的模型、预计日调用量、峰值并发和结算需求。管理员确认权限、账户分组及报价后开通；VIP 不通过模型后缀或自定义请求头获得。

## 多环境与密钥管理

开发、测试和生产建议使用独立 Key，避免多人共享。Key 额度和账号余额是不同约束；任一不足都可能阻止请求。泄露或失效时禁用旧 Key、更新业务配置并核对异常调用。

遇到登录或安全验证问题请按页面提供的流程处理，不跳过账号验证。模型请求的 Bearer 配置见 [鉴权与地址](/getting-started/authentication)。
