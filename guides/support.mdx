[进入控制台](https://vizluma.online/console) 查看自己的任务与消费记录。已有企业客户也可使用 [企业控制台](https://sub.vizluma.online)；页面入口以你的账户权限为准。

## 任务与消费是两类记录

| 记录 | 用途 | 注意事项 |
| --- | --- | --- |
| 任务记录 | 查看排队、执行、完成与结果 | 新版图片记录不能补齐所有历史请求 |
| 消费记录 | 核对最终用量、分组与费用 | 查询成功或生成中状态不等于已最终结算 |
| 本地业务记录 | 关联你的订单、任务 ID 与重试 | 不存储可用 Key、Cookie 或完整鉴权头 |

创建时将业务编号与图片幂等键、任务 ID 一起保存。文本使用可获得的请求 ID，视频保存创建返回的 ID。发生网络断连后，先凭这些标识核对原请求。

## 对账顺序

1. 使用正确的账户、时间范围与时区筛选。
2. 比对模型 ID、结果状态、图片数／Token／视频时长。
3. 按账户分组及实际报价核对费用，VIP 折扣只算一次。
4. 区分额度预留与最终结算；结果待确认时不要自行推断必定退款。
5. 有差异时提交请求 ID 和脱敏记录，由现有对接人员核查。

本页不提供未经确认的余额、日志或令牌管理 API；模型调用 Key 不能直接拿去访问其他平台的账户接口。

## 支持材料模板

```text
调用时间与时区：2026-11-11 23:00 Asia/Shanghai
接口：POST /v1/images/generations
模型：gpt-image-2
HTTP 状态：504
请求 ID：实际响应中的值；没有则注明未取得
任务 ID：实际返回的 id；没有则注明未取得
现象：提交后超时，任务目前 UNKNOWN
主要参数：size=1024x1024, n=1, response_format=url
已采取的操作：仅查询原任务，未换键重发
期望处理：确认原任务结果和最终费用
```

请通过你已有的商务或技术支持渠道提交。不要发送 API Key、密码、Cookie、完整请求头；素材、提示词和响应包含业务秘密时先脱敏。本站不虚构客服联系方式或响应时限。
