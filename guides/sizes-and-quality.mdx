## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `size` | string | 否 | 图片尺寸，例如 `1024x1024`；也可使用 `16:9` 等比例值 |
| `resolution` | string | 否 | 输出规格：`1k`、`2k`、`4k`，与比例形式的 size 配合使用 |
| `quality` | string | 否 | 质量档位，见下表；省略时使用模型默认值 |

## quality 质量参数

| 值 | 说明 |
| --- | --- |
| `low` | 低质量档位 |
| `medium` | 中等质量档位 |
| `high` | 高质量档位 |
| `xhigh` | 扩展质量档位，适用于 GPT Image 2.5 Sunburst |
| `max` | 扩展质量档位，适用于 GPT Image 2.5 Sunburst |

`quality` 与 `size` 分别设置。调整质量档位不会修改所请求的像素尺寸。

```json
{
  "model": "gpt-image-2.5-sunburst",
  "prompt": "一只橘猫，简洁插画，纯白背景",
  "size": "1024x1024",
  "quality": "medium",
  "n": 1,
  "response_format": "url"
}
```

完整调用见 [生成图片](/api-reference/images-generations)，右侧支持 cURL、Python 和 Node.js。

## 像素尺寸与输出规格

| size 示例 | 输出规格 |
| --- | --- |
| `1024x1024` | 1K |
| `2048x2048` | 2K |
| `2048x1152` | 2K |
| `3840x2160` | 4K |
| `2160x3840` | 4K |
| `2880x2880` | 4K |

1K、2K、4K 是输出规格名称，不表示每条边均为 1024、2048 或 4096 像素。

## 比例与 resolution

使用比例形式的 `size` 时，可通过 `resolution` 指定输出规格：

```json
{
  "model": "gpt-image-2.5-sunburst",
  "prompt": "海边日落，横向构图",
  "size": "16:9",
  "resolution": "2k",
  "quality": "medium",
  "n": 1,
  "response_format": "url"
}
```

像素尺寸与 `resolution` 应保持一致。`resolution` 是扩展字段，SDK 调用时需使用其自定义请求体功能。

## 型号与计费

| 系列 | 尺寸参数 | 计费 |
| --- | --- | --- |
| GPT Image 2／2.5 | 像素 size，或比例 size + resolution | 1K／2K／4K 同价 |
| GPT Image 2.6 | 像素 size，或比例 size + resolution | 按 1K／2K／4K 分档 |
| Gemini 图像 | 比例 size + resolution | 见对应型号价格 |

GPT Image 按实际图片数量及输出规格计费，`quality` 不单独加价。具体单价见 [计费说明](/pricing)。Gemini 的尺寸和参数见 [Gemini 图像](/models/gemini-image)。
