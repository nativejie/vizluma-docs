| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 已开通权限的完整模型 ID，见 [模型列表](/models/overview)。 |
| `prompt` | string | 是 | 非空的图像描述。建议说明主体、风格、构图、背景和文字要求。 |
| `size` | string | 否 | 建议显式使用 `1024x1024` 开始联调。其他尺寸见 [尺寸说明](/guides/sizes-and-quality)。 |
| `n` | integer | 否 | 默认 `1`；网关接受 `1`～`10`，批量能力与企业调用限制需单独确认。按实际返回图片数量计费。 |
| `response_format` | string | 否 | `url` 或 `b64_json`。建议显式指定；本文的已实测基础示例使用 `url`。 |

`stream: true` 和 `mask` 不在当前支持范围内。不要假设官方接口的所有扩展参数在这里都可用。
