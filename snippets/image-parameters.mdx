| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 已开通权限的完整模型 ID，见 [模型列表](/models/overview)。 |
| `prompt` | string | 是 | 非空的图像描述。建议说明主体、风格、构图、背景和文字要求。 |
| `size` | string | 否 | 建议显式使用 `1024x1024` 开始联调。其他尺寸见 [尺寸说明](/guides/sizes-and-quality)。 |
| `quality` | string | 否 | GPT Image 质量档位：`low`、`medium`、`high`；2.5 Sunburst 还可传 `xhigh`、`max`。省略时使用模型默认值，见 [质量参数](/guides/sizes-and-quality#quality-质量参数)。 |
| `n` | integer | 否 | 默认 `1`；GPT Image 接受 `1`～`10`，Gemini 图像仅 `1`；批量能力与企业调用限制需单独确认。按实际返回图片数量计费。 |
| `response_format` | string | 否 | `url` 或 `b64_json`。建议显式指定；示例使用 `url`。 |

`stream: true` 和 `mask` 不在当前支持范围内。不要假设官方接口的所有扩展参数在这里都可用。

Gemini 的 `resolution`、比例、质量和参考图限制见 [Gemini 图像](/models/gemini-image)，不要直接套用 GPT Image 的全部可选参数。
