## 1. 准备 API Key

先 [注册或登录并获取 Key](/getting-started/enterprise-access)，确认模型权限与可用额度。把 Key 配置在自己的服务端或安全本地终端：

```bash
export VIZLUMA_API_KEY="YOUR_API_KEY"
export VIZLUMA_BASE_URL="https://api.vizluma.online/v1"
```

`YOUR_API_KEY` 是占位符，生产环境通过密钥管理系统注入。不要将 Key 放入网页前端。

## 2. 选择第一条请求

<Tabs>
<Tab title="文本对话">

```bash
curl --fail-with-body --silent --show-error --max-time 120 \
  "${VIZLUMA_BASE_URL%/}/chat/completions" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-6.1-sol","messages":[{"role":"user","content":"Reply with exactly OK."}],"reasoning_effort":"low","max_completion_tokens":128,"stream":false}' \
  -o chat.json
```

读取 `choices[0].message.content`。完整字段见 [Chat Completions](/api-reference/chat-completions)，使用流式时见 [SSE](/guides/streaming)。

</Tab>
<Tab title="生成图片">

```bash
curl --fail-with-body --silent --show-error \
  --connect-timeout 15 --max-time 600 \
  "${VIZLUMA_BASE_URL%/}/images/generations" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"一只小橘猫坐在纯白色背景上，简洁插画，无文字","size":"1024x1024","n":1,"response_format":"url"}' \
  -o generation.json
```

默认等待生成完成。读取 `data[].url`，再 [下载并保存图片](/guides/image-results)。`generation.json` 是接口响应，不是图片文件。

想先取得任务 ID、稍后查询，见 [异步完整示例](/guides/async-images)。

</Tab>
<Tab title="视频任务">

```bash
curl --fail-with-body --silent --show-error --max-time 60 \
  "${VIZLUMA_BASE_URL%/}/videos" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"seedance-2.5-480p","prompt":"A cat walking slowly on a sunny beach","duration":5,"ratio":"16:9","resolution":"480p"}' \
  -o video-task.json
```

先保存顶层 `id`。通过 `GET /v1/videos/{id}` 查询，状态为 `completed` 后访问 `GET /v1/videos/{id}/content` 下载。完整流程见 [视频 API](/api-reference/videos)。

视频配置已启用，付费生成与下载仍待实测；请先小规模验证自己的素材和规格。

</Tab>
</Tabs>

## 3. 检查调用结果

| 请求类型 | 应保存的信息 | 成功判断 |
| --- | --- | --- |
| 同步文本 | 回复、完成原因及用量 | HTTP 成功且有完整业务结果 |
| 同步图片 | 响应及实际图片 | 有可下载 URL 或可解码图片 |
| 异步图片 | 任务 ID、原幂等键及最终 result | 任务 `SUCCESS` 并取得图片 |
| 视频 | 任务 ID 及最终视频文件 | 任务 `completed` 并下载成功 |

图片异步的 HTTP `202` 只表示接受任务。查询的 HTTP `200` 只表示查询成功。费用请在 [控制台](https://vizluma.online/console) 核对，价格说明见 [计费](/pricing)。
