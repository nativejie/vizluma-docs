## 接入地址

| 用途 | 地址 |
| --- | --- |
| API Base URL | `https://api.vizluma.online/v1` |
| 官网与账号入口 | [vizluma.online](https://vizluma.online) |
| 客户控制台 | [vizluma.online/console](https://vizluma.online/console) |
| 企业控制台 | [sub.vizluma.online](https://sub.vizluma.online) |
| 开发文档 | [docs.vizluma.online](https://docs.vizluma.online) |

模型请求统一发往 API 域名。新用户可从 [注册与获取 Key](/getting-started/enterprise-access) 开始；企业专属额度、权限与报价请联系已有对接人员。

## 开发到上线

<Steps>
  <Step title="确认 Key 与模型">在控制台配置 API Key，通过 [模型查询](/api-reference/models) 核对可见型号。</Step>
  <Step title="跑通最小请求">按 [快速开始](/quickstart) 完成请求与结果读取，再接入自己的业务输入。</Step>
  <Step title="处理完成与失败">文本识别流结束；图片保存结果；视频保存 ID 并轮询。查看 [错误处理](/api-reference/errors)。</Step>
  <Step title="控制成本与并发">按 [价格](/pricing)、[调用限制](/guides/limits) 设置输出上限、队列与超时，在控制台核对消费。</Step>
</Steps>

## 能力范围

文档区分已完成真实调用、已配置但待实测及需单独确认的能力。不要把格式兼容理解为支持官方全部参数；具体型号限制见对应模型页。遇到问题，可先查看 [排障指南](/guides/troubleshooting) 和 [支持材料](/guides/support)。
