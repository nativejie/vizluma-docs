Vizluma API 为企业应用提供统一的 AI 接口。你可以通过服务端 HTTP 请求调用模型，并将结果接入自己的产品、工作流或内容生产系统。

<Info>
  Vizluma API 采用企业开通制，**不开放自助注册**。请通过与你对接的商务或管理员开通账号、确认模型权限并获取 API Key。
</Info>

## 接入地址

| 用途 | 地址 |
| --- | --- |
| API Base URL | `https://api.vizluma.online/v1` |
| 企业控制台 | [sub.vizluma.online](https://sub.vizluma.online) |
| 文档 | `https://docs.vizluma.online` |

**模型请求发往 API 域名，不要发往控制台或文档域名。**

## 当前可用的生图模型

- `gpt-image-2`
- `gpt-image-2.5-flare`
- `gpt-image-2.5-sunburst`

三个模型均已完成单张 `1024x1024`、URL 返回模式的文生图及链接／上传编辑联调，详见 [图片编辑](/api-reference/images-edits)。模型权限由企业账号的实际配置决定。

本文档不将“兼容 OpenAI Images 请求格式”等同于支持官方接口的全部参数。已确认的参数见 [图片生成](/api-reference/images-generations)；尚未验证的能力会明确标注。其他图像、文本和视频模型将在开放后补充，不代表当前已经可用。
