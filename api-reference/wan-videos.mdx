本页仅介绍 Wan 3.0。视频任务通过 JSON 创建，保存任务 ID 后查询状态，完成后下载 MP4。先配置 [API Key 与地址](/getting-started/authentication)。

## 模型与规格

| 模型 ID | 固定 `resolution` | `duration` |
| --- | --- | --- |
| `wan3.0-video-480p` | `480p` | 2～30 秒 |
| `wan3.0-prime-720p` | `720p` | 2～30 秒 |
| `wan3.0-prime-1080p` | `1080p` | 2～30 秒 |

时长必须是整数，省略时默认 5 秒。分辨率由模型决定，显式传入 `resolution` 时必须匹配所选模型。价格按秒计算，见 [Wan 价格](/pricing#wan-3-0-视频价格)。

## 第一步：创建任务

每次执行创建请求都会提交一个新视频任务，不要因网络超时无条件重发。

```bash wan-create.sh
set -euo pipefail
: "${VIZLUMA_API_KEY:?请先设置 VIZLUMA_API_KEY}"
BASE_URL="${VIZLUMA_BASE_URL:-https://api.vizluma.online/v1}"
curl --fail-with-body --silent --show-error --max-time 60 \
  "${BASE_URL%/}/videos" \
  -H "Authorization: Bearer ${VIZLUMA_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"model":"wan3.0-video-480p","prompt":"A cat walking slowly on a sunny beach, gentle waves in the background","duration":5,"ratio":"16:9","resolution":"480p"}' \
  --output wan-task.json
cat wan-task.json
```

将响应的顶层 `id` 与业务编号一起保存。下例为结构示意，ID 为占位值：

```json
{
  "id": "video_example",
  "object": "video",
  "status": "queued"
}
```

创建成功表示任务已提交，不代表已经生成完成。不要使用其他平台返回的任务 ID。

## 第二步：查询状态

将实际 ID 配置为 `WAN_VIDEO_ID`，建议每 30 秒查询一次，始终查询原任务：

```bash wan-status.sh
set -euo pipefail
: "${VIZLUMA_API_KEY:?请先设置 VIZLUMA_API_KEY}"
: "${WAN_VIDEO_ID:?请设置创建响应中的 id}"
BASE_URL="${VIZLUMA_BASE_URL:-https://api.vizluma.online/v1}"
curl --fail-with-body --silent --show-error --max-time 60 \
  "${BASE_URL%/}/videos/${WAN_VIDEO_ID}" \
  -H "Authorization: Bearer ${VIZLUMA_API_KEY}"
```

| `status` | 处理方式 |
| --- | --- |
| `queued` | 等待后查询原任务 |
| `in_progress` | 继续查询原任务 |
| `completed` | 下载视频 |
| `failed` | 停止轮询，保存错误并核对最终费用 |

查询 HTTP `200` 只表示查询成功。查询超时或出现未知状态时，保留任务 ID 核查，不把它当作创建失败自动重发。

## 第三步：下载 MP4

仅在状态为 `completed` 后执行。下载接口仍需同一账户的有效 API Key，及时保存到自己的存储中。

```bash wan-download.sh
set -euo pipefail
: "${VIZLUMA_API_KEY:?请先设置 VIZLUMA_API_KEY}"
: "${WAN_VIDEO_ID:?请设置已完成任务的 id}"
BASE_URL="${VIZLUMA_BASE_URL:-https://api.vizluma.online/v1}"
curl --fail --silent --show-error --max-time 600 \
  "${BASE_URL%/}/videos/${WAN_VIDEO_ID}/content" \
  -H "Authorization: Bearer ${VIZLUMA_API_KEY}" \
  --output wan.mp4
```

下载失败时优先重试原文件下载，不要重新创建视频。返回文件不保证永久保存，也不要将 API Key 转发到第三方素材地址。

## 参数与素材限制

| 字段 | 说明 |
| --- | --- |
| `model` | 必填，使用本页三个完整 ID 之一 |
| `prompt` | 本页纯文本示例的生成指令 |
| `duration` | 2～30 的整数，默认 5；不能用 `-1` 自动时长 |
| `seconds` | 时长别名；与 `duration` 同传时必须一致 |
| `resolution` | 可省略；传入时必须匹配模型固定规格 |
| `ratio` | 本页示例为 `16:9`，其他比例需按型号联调 |
| `reference_images` | 最多 10 项，使用可访问的图片 URL 或 `image_url` 对象 |
| `reference_audios` | 最多 5 项，使用可访问的音频 URL 或 `audio_url` 对象 |
| `reference_videos` | 当前不支持参考视频输入 |

本页已给出纯文本创建示例；参考素材的格式、组合和生成效果需按业务实测。不要混入任意 `metadata`、批量参数 `n`、本地路径、Base64 或 multipart 文件上传；未声明或未确认的扩展字段不要自行套用。

## 接入状态与重试

三个 Wan 型号已配置启用，已有本地协议及计费测试；真实付费生成、MP4 下载和素材组合仍待实测。这里的时长是网关校验范围，不保证区间内每一种请求组合都被模型接受。

创建请求没有本文承诺的幂等去重；图片 `Idempotency-Key` 和 `/v1/images/tasks` 不适用于本页视频流程。保留原任务查询结果，按 [错误处理](/api-reference/errors) 与 [超时说明](/guides/timeouts-and-retries) 处理不确定状态。

## Python 后台任务完整示例

首次明确执行 `create` 才创建一次任务，随后轮询状态并下载；中断后使用 `resume` 和原 ID，不重新生成。需要 Python 3.10+ 和已有 API 环境变量。每个业务使用独立目录。

```bash
python3 wan-task.py create
```

```python wan-task.py
import json
import os
import shutil
import sys
import time
import urllib.error
import urllib.parse
import urllib.request
from pathlib import Path

key = os.environ.get("VIZLUMA_API_KEY")
if not key or key == "YOUR_API_KEY":
    raise SystemExit("请先配置 VIZLUMA_API_KEY")
args = sys.argv[1:]
if args != ["create"] and not (len(args) == 2 and args[0] == "resume" and args[1]):
    raise SystemExit("用法：python3 wan-task.py create | resume 实际任务ID")
base = os.environ.get("VIZLUMA_BASE_URL", "https://api.vizluma.online/v1").rstrip("/")


class NoRedirect(urllib.request.HTTPRedirectHandler):
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        return None


opener = urllib.request.build_opener(NoRedirect())


def open_api(path, body=None):
    headers = {"Authorization": "Bearer " + key}
    data = None
    if body is not None:
        data = json.dumps(body).encode("utf-8")
        headers["Content-Type"] = "application/json"
    try:
        return opener.open(urllib.request.Request(base + path, data=data, headers=headers), timeout=60)
    except urllib.error.HTTPError as error:
        raise SystemExit(f"HTTP {error.code}，保留原任务ID核对，不自动创建替代任务")
    except (urllib.error.URLError, TimeoutError):
        raise SystemExit("网络结果不确定，请保留原任务ID与记录，不重复创建")


if args[0] == "create":
    with open_api("/videos", {
        "model": "wan3.0-video-480p",
        "prompt": "A cat walking slowly on a sunny beach, gentle waves in the background",
        "duration": 5, "ratio": "16:9", "resolution": "480p",
    }) as response:
        created = json.load(response)
    task_id = created.get("id")
    if not isinstance(task_id, str) or not task_id:
        raise SystemExit("未取得任务ID，先核对创建记录，不自动重发")
    Path("wan-task.json").write_text(json.dumps(created, ensure_ascii=False), encoding="utf-8")
else:
    task_id = args[1]
print("任务ID：" + task_id, flush=True)
path = "/videos/" + urllib.parse.quote(task_id, safe="")
deadline = time.monotonic() + 600
while time.monotonic() < deadline:
    with open_api(path) as response:
        task = json.load(response)
    Path("wan-status.json").write_text(json.dumps(task, ensure_ascii=False), encoding="utf-8")
    state = task.get("status")
    if state == "completed":
        output = Path("wan.mp4")
        if output.exists():
            raise SystemExit("本地视频文件已存在，请先确认或更换独立工作目录")
        partial = output.with_suffix(".mp4.part")
        with open_api(path + "/content") as response:
            content_type = response.headers.get("Content-Type", "").split(";", 1)[0].lower()
            if not content_type.startswith("video/") and content_type != "application/octet-stream":
                raise SystemExit("下载内容类型不是视频，请保留任务ID核查")
            with partial.open("wb") as file:
                shutil.copyfileobj(response, file)
        if not partial.stat().st_size:
            raise SystemExit("下载为空，保留任务ID后重试原文件下载")
        partial.replace(output)
        print("视频已保存为 " + str(output))
        break
    if state not in ("queued", "in_progress"):
        raise SystemExit(f"任务状态 {state}，停止自动处理并核对原任务")
    time.sleep(30)
else:
    raise SystemExit("本地等待结束，任务可能仍在运行；使用 resume 和原ID继续")
```

任务 ID 会立即打印并写入 `wan-task.json`。600 秒本地等待结束或程序中断后，使用实际 ID：

```bash
python3 wan-task.py resume video_replace_with_actual_id
```

`resume` 不发送创建请求。失败、未知状态和网络问题不会自动创建替代视频；下载只访问本站内容接口，并拒绝自动跟随重定向。

| 本地文件 | 内容 |
| --- | --- |
| `wan-task.json` | 首次创建返回的任务对象 |
| `wan-status.json` | 最近一次查询结果 |
| `wan.mp4.part` | 下载中的临时文件 |
| `wan.mp4` | 下载完成的视频文件 |

创建响应未保存就断网时，先核对调用记录，不能因为没有本地文件就确认未创建。轮询和等待上限是客户端策略，不是生成时限保证；真实付费生成与素材能力仍以本页验证范围为准。
