<Warning>
  图片编辑尚未完成当前部署下的端到端验收，**不作为本版文档已验证的生产接入能力**。请先联系对接人员确认模型、输入格式、输出规格和计费，再进行联调。
</Warning>

规划中的对接路径为：

```text
POST https://api.vizluma.online/v1/images/edits
```

网关已有 JSON／文件上传形式的编辑接入实现，但“路由存在”不等于实际模型服务的行为已经验证。本页暂不提供可直接复制到生产的编辑请求示例。

## 验收后补充的内容

- 支持的模型及参考图片数量。
- JSON 图片链接与 multipart 文件上传示例。
- 输入文件格式、体积与尺寸限制。
- 请求尺寸、输出尺寸及其价格档位。
- 生成失败、部分返回及超时的处理方式。

## 当前边界

- 不承诺 `mask` 局部编辑；当前网关会拒绝该参数。
- 不承诺透明背景或所有官方编辑参数。
- 不要因为文生图调用成功，就认为编辑调用同样可用。

可以先完成 [文生图接入](/api-reference/images-generations)。编辑联调完成后，本页会补充经过实际调用验证的示例，而不是直接照搬其他服务商的教程。
