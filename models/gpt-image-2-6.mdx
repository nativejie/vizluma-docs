使用与 GPT Image 2／2.5 相同的 [生成](/api-reference/images-generations)、[编辑](/api-reference/images-edits) 和 [异步任务](/api-reference/image-tasks) 接口。不能简写为 `gpt-image-2.6`。

## 最小请求

```bash image26.sh
curl --fail-with-body --silent --show-error \
  --connect-timeout 15 --max-time 600 \
  "${VIZLUMA_BASE_URL%/}/images/generations" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2.6-flare","prompt":"白色陶瓷杯，纯白背景，商品插画，无文字","size":"1024x1024","n":1,"response_format":"url"}' \
  -o generation.json
```

切换 Sunburst 只替换完整模型 ID。请先配置 [环境变量](/getting-started/authentication)。
