## 选择协议

| 你的应用 | 接入方式 | 读取文本 |
| --- | --- | --- |
| 原本使用 Anthropic 消息格式 | `POST /v1/messages` | `content[]` 中 `type=text` 的 `text` |
| 已有 OpenAI 格式聊天应用 | `POST /v1/chat/completions` | `choices[].message.content` |

使用 Anthropic 格式的消息块与事件时，选择 [Messages API](/api-reference/messages)；已有 OpenAI 格式聊天应用可选择 Chat Completions。

## Chat 兼容示例

```bash claude-chat.sh
curl --fail-with-body --silent --show-error --max-time 120 \
  "${VIZLUMA_BASE_URL%/}/chat/completions" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5-5","messages":[{"role":"user","content":"Reply with exactly OK."}],"max_tokens":128,"stream":false}' \
  -o claude-chat.json
```

准备环境变量见 [鉴权与地址](/getting-started/authentication)。原生协议的完整请求、响应与流式事件见 [Messages 参考](/api-reference/messages)。请求中使用上表列出的完整模型 ID。

## 价格与缓存

按非缓存输入、输出、缓存读取、5 分钟与 1 小时缓存写入分别计价。Haiku 5.5 按总输入 100,000 Token 分档，其他本页型号当前为单档。人民币单价见 [Claude 价格表](/pricing#claude-文本价格)，不能统一假设缓存读取是输入价的某个固定百分比。
