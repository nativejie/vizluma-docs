## 模型 ID

| 模型 | 请求中的 `model` |
| --- | --- |
| Flare | `gpt-image-2.5-flare` |
| Sunburst | `gpt-image-2.5-sunburst` |

请求时使用完整模型 ID，不要简写为 `gpt-image-2.5`。

## 调用示例

先完成 [环境变量配置](/getting-started/authentication)，再选择一个模型：

<CodeGroup>

```bash Flare
curl --fail-with-body --silent --show-error \
  --connect-timeout 15 --max-time 600 \
  "$VIZLUMA_BASE_URL/images/generations" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-flare",
    "prompt": "生成一张白色陶瓷杯的商品插画，杯子居中，纯白背景，柔和阴影，无文字",
    "size": "1024x1024",
    "quality": "medium",
    "n": 1,
    "response_format": "url"
  }' \
  -o generation.json
```

```bash Sunburst
curl --fail-with-body --silent --show-error \
  --connect-timeout 15 --max-time 600 \
  "$VIZLUMA_BASE_URL/images/generations" \
  -H "Authorization: Bearer $VIZLUMA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "生成一张白色陶瓷杯的商品插画，杯子居中，纯白背景，柔和阴影，无文字",
    "size": "1024x1024",
    "quality": "medium",
    "n": 1,
    "response_format": "url"
  }' \
  -o generation.json
```

</CodeGroup>

响应结构与 GPT Image 2 相同，见 [图片生成 API](/api-reference/images-generations)。返回 URL 后请及时保存图片。

## 参数

<ImageParameters />

### quality 质量档位

使用 `quality` 指定质量档位，例如 `quality: "medium"`。可选值及尺寸写法见 [尺寸与质量参数](/guides/sizes-and-quality#quality-质量参数)。

## 从 GPT Image 2 切换

1. 请管理员确认当前 Key 已开通目标 2.5 模型。
2. 在现有请求中替换完整 `model` ID。
3. 设置 `size`、`quality`、`n` 和 `response_format`。
4. 读取 `data[].url` 获取生成结果。

两个 2.5 模型与 GPT Image 2 的公开基础价均为 ¥0.20／张，1K／2K／4K 同价，见 [计费说明](/pricing)。

图片链接与文件上传的调用方式见 [图片编辑](/api-reference/images-edits)。
